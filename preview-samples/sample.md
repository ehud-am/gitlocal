# Markdown Preview Sample

This file demonstrates GitLocal's **Markdown** preview, rendered via `react-markdown` + `remark-gfm`.

## Features

- Bullet lists
- **Bold** and *italic* text
- `inline code`
- [Links](https://gitlocal.dev)
