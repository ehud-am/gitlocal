## Scope

- Release: `v0.15.0` (MINOR).
- Theme: previews and navigation from open issues #113, #114, #117, #118, plus dependency update #124.
- Release date: 2026-10-24

## Summary of changes

- HTML preview (#117): new `html` `FileContentType` for `.html`/`.htm` (`detectFileType`), editable as text (`isInlineEditableType` in `src/git/repo.ts`, used by the edit check and `PUT /api/file`). `HtmlViewer.tsx` renders `srcdoc` in an iframe with `sandbox="allow-same-origin"` (no scripts, forms, popups or top navigation; same-origin only so the frame can be sized to its content). `buildPreviewDocument` injects a CSP meta (`default-src 'none'`; inline styles and `data:` images/fonts/media allowed) and `<base target="_blank">` after the doctype, and disables `<meta http-equiv="refresh">`. If a `target="_self"` link navigates the frame to a web page, the preview is reset (`frameLeftPreview`). Raw toggle shows highlighted source.
- JSON view (#114): `JSONViewer.tsx` renders JSON as formatted source (quoted keys, commas, braces, indent guides) with token colors defined as CSS variables for light and dark themes; folding kept, with "N keys"/"N items" summaries. Parsing (`json-tree.ts`) unchanged.
- Go to path (#118): `GoToPathDialog.tsx` from a header "Go to" button and Ctrl+Alt+G. `resolveGoToPath` (`ui/src/lib/go-to-path.ts`) maps input to root, in-root (relative, or absolute under the open root; POSIX and Windows separators, Windows roots case-insensitive) or external. In-root paths are typed via `GET /api/sync` (`currentPathType`) and selected in place; external paths use `POST /api/repo/open` and `applyLocalOpenResponse`, the same flow as a native open-file event. The open handler now expands `~` and `~/` (`expandHomePath`), which also applies to the picker.
- Terminal (#113): side-dock default width ratio 1/3 -> 1/2 (`DEFAULT_PANEL_WIDTH_RATIO`).
- Dependencies (#124): hono 4.13.13, vite 8.3.5 (root and `ui/`). vitest/@vitest/coverage-v8 4.1.12 and zod 4.6.7 (via knip, dev only) for GHSA-qxg6-89mg-rqv8, GHSA-xp26-3454-mjgp and GHSA-mrhx-c7xc-m3w5, which failed CI's `npm audit`; lockfiles regenerated with npm 11.

## Verification

- Server tests with coverage, run as a non-root user: 493 passed, thresholds met. As root, 13 permission-based tests fail before and after this change (root ignores `chmod`).
- UI tests with coverage: all passed, per-file thresholds met. New/changed tests: `HtmlViewer.test.tsx`, `JSONViewer.test.tsx`, `GoToPathDialog.test.tsx`, `go-to-path.test.ts`, App "go to path" cases, registry, server `detectFileType`, `/api/file` html read/update, `~` expansion.
- `npm run lint`, `cd ui && npx tsc --noEmit -p .`, `npm run build`: clean.
- Chromium against the built app: HTML page renders with inline styles, its `<script>` blocked by the sandbox, remote stylesheet and image blocked by CSP (no external request completed), frame sized to content; JSON view in light theme; Go to opened `docs/guide.md` in place and an outside folder via Ctrl+Alt+G in dark theme.
- Not verified here: WebKit (macOS app) rendering of the HTML frame [likely same as Chromium; `srcdoc`, `sandbox` and meta CSP are supported in WebKit].
- Local install note: `ui` `npm ci` could not fetch the SheetJS CDN tarball from this environment; tests ran with the npm-registry `xlsx` installed locally only. Lockfiles were not changed for this.
