# GitLocal v0.11.0 Release Review

## Scope

- Release: `v0.11.0` — three pieces of work on `036-file-preview-framework` (3 commits ahead of `origin/main`):
  1. `99cef37` — the `036-file-preview-framework` epic: an extensible file preview registry, plus new read-only PDF and SVG preview support.
  2. `9b1120c` — fixes for 2 GitHub code-scanning alerts (incomplete HTML-comment stripping in Markdown rendering; missing least-privilege permissions on a CI workflow) found while reviewing the epic.
  3. `32cf346` — linked gitlocal.dev from both READMEs and optimized the gitlocal.dev site for AI/search discovery.
- Branch: `036-file-preview-framework`, 41 files changed, 2028 insertions(+), 55 deletions(-) vs `origin/main`.
- Release date: 2026-08-29

## Summary of changes

- **File preview framework**: `preview-registry.tsx` maps each file content type (markdown, json, text, image, binary, pdf, svg) to its preview component, replacing an implicit if/else chain with an explicit table. Migration of existing types was behavior-preserving. New: `PdfViewer.tsx` (read-only, `pdfjs-dist` lazily loaded with a locally-bundled worker — no CDN fetch) and `SvgViewer.tsx` (rendered as an inert `<img>` data URI so embedded SVG scripts never execute). Along the way, fixed a gap where a file type's own `editable` flag could override the registry's read-only setting for that type — `canEditFile` now requires both.
- **Security fixes** (GitHub code scanning): `stripHtmlComments` in `markdown-output.ts`/`markdown-navigation.ts` used a single non-global regex pass, so adjacent/overlapping HTML comments could survive sanitization; replaced with a loop that strips until no comment markers remain. `.github/workflows/ci.yml` was missing an explicit top-level `permissions` block, so jobs ran with the broader default token scope; added least-privilege permissions.
- **Website/discoverability**: added a website badge and callout to `README.md` and `packaging/npm/README.md` (the file actually published to npmjs.com), and set `package.json`'s `homepage` to `https://gitlocal.dev`. On the site itself (`docs/`): canonical URL, robots meta, Open Graph and Twitter Card tags, JSON-LD `SoftwareApplication` + `FAQPage` structured data, a visible 6-question FAQ section matching the structured data, plus `robots.txt`, `sitemap.xml`, and `llms.txt` (an emerging AI-crawler convention).

## Known, accepted build warning

- The UI build reports one chunk over 500 kB (`pdf.worker.min-*.mjs`, ~1.26 MB minified) — the `pdfjs-dist` worker. This is a deliberate trade-off from `specs/036-file-preview-framework/research.md`: the worker is bundled locally (never fetched from a CDN) so PDF preview keeps working offline and never leaks file activity to a third party. Not a regression introduced by this release's changes; not treated as a blocker.
