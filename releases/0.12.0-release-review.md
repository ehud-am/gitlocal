## Summary of changes

- **CSV preview**: `.csv` files now render as a scrollable table (first row as header) via lazily-loaded `papaparse`, replacing the previous plain-text fallback. A raw/pretty toggle matches the existing Markdown/JSON/SVG pattern. Quoted fields, embedded commas, and embedded newlines are parsed correctly rather than split naively. Malformed/empty CSVs get a clear fallback instead of crashing.
- **Excel workbook preview**: `.xlsx`/`.xls` files now render the active worksheet's cell values as a table (previously "Binary file — preview not available"), with a per-sheet tab strip for multi-sheet workbooks. Cell values are the file's last-saved cached values — formulas are never recalculated, external data links are never refreshed, and macros/dynamic content are never executed, all via SheetJS Community Edition's static-parse API. Both new viewers are `editable: false` and registered through `preview-registry.tsx` with zero changes to `ContentPanel.tsx`'s core dispatch logic, matching spec 036's established pattern.
- **Chart indicator (reduced scope)**: User Story 3 shipped as a static "this sheet contains a chart" label shown only on a sheet that is itself a dedicated chart tab. SheetJS Community Edition was empirically confirmed to expose no chart title, no cached series data, and no detectable signal at all for a chart embedded inside a normal worksheet — confirmed with the feature requester before implementation, so the deeper chart-preview scope was intentionally dropped rather than attempted with unreliable signal.
- **Coverage gate fix**: `ui/vitest.config.ts`'s coverage `include` list was missing the preview-framework's own viewer components (pre-existing gap from spec 036), so the gate wasn't actually enforcing coverage on `CsvViewer.tsx`/`ExcelViewer.tsx`/etc. Fixed as part of this release.
- **Docs/dev-only additions** (not part of the npm-published package — excluded via `package.json`'s `files` allowlist): install-doc polish for macOS Gatekeeper `xattr` guidance, source assets for a future promo GIF, and a `preview-samples/` folder demonstrating every supported preview type for manual QA.

## Known, accepted build warnings

- The UI build reports several chunks over 500 kB after minification: `pdf.worker.min-*.mjs` (~1.26 MB, pre-existing from spec 036), `index-*.js` (~714 kB), `pdf-*.js` (~428 kB), and the new `ExcelViewer-*.js` (~365 kB, driven by the SheetJS CE bundle). All preview libraries (`papaparse`, `xlsx`, `pdfjs-dist`) are lazily loaded on first use of that file type, so these chunks are not part of the initial app bundle. Not treated as a blocker.
