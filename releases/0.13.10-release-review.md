# GitLocal v0.13.10 Release Review

## Scope

- Release: `v0.13.10` (PATCH). Fix PR #121.
- Theme: PowerPoint text formatting set at paragraph level.
- Release date: 2026-10-11

## Summary of changes

- Text runs with no `a:rPr` of their own now take color, size, weight and font from the
  paragraph's `a:pPr/a:defRPr`, ahead of the shape/layout/master list styles. A run's own
  `rPr` still wins. Before, such runs rendered black, 18pt, theme font: invisible on dark
  slides in decks from generators that format text only at paragraph level.
- UI only; no server or API change.

## Verification

- UI suite: 57 files, 885 tests passing, per-file coverage gate met (`text.ts` 96.8% branches).
  New `text.test.ts` case covers paragraph defaults vs run properties vs list style.
- CI `verify` on #121: green.
- Reported 21-slide deck: every slide compared with LibreOffice output; fonts, sizes and colors
  match.
- Seven corpus decks that use paragraph `defRPr`: first six slides pixel-compared before/after;
  no visible change (anti-aliasing noise only).
