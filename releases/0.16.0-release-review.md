# GitLocal v0.16.0 Release Review

## Scope

- Release: `v0.16.0` (MINOR).
- Theme: Word document preview, issue #115.
- Release date: 2026-10-27
- No new dependency. The parser reuses the PPTX preview's `jszip` + `DOMParser` stack.

## Summary of changes

- Server: new `docx` `FileContentType` for `.docx`, `.docm`, `.dotx`, `.dotm` (`detectFileType` in `src/git/repo.ts`). `.docx` removed from the binary list; `.doc` stays binary. `/api/file` sends it base64 with `editable: false`, in the same branch as `excel` and `pptx` (`src/handlers/file.ts`).
- UI: `DocxViewer.tsx`, registered in `preview-registry.tsx` (no raw toggle, not editable), lazily loading `docx/document.ts`.
  - `docx/properties.ts`: run and paragraph properties as partial layers; Word colors (hex, `auto`, `themeColor` with `themeTint`/`themeShade`), shading, borders, highlight, underline styles, tab stops, numbering references.
  - `docx/styles.ts`: document defaults, paragraph and character styles through `w:basedOn` (cycle-safe), table styles split into conditional regions (`w:tblStylePr`).
  - `docx/numbering.ts`: list levels and counters (decimal, roman, letters, ordinal, circled, bullets; `%1.%2` templates, `isLgl`, `startOverride`, `lvlOverride`, `numStyleLink`). Symbol/Wingdings bullets are mapped to Unicode.
  - `docx/document.ts`: body split into sheets at hard page breaks and section breaks, with each section's page size, margins, columns, header and footer (`titlePg` first-page header). Complex and simple fields (results shown, codes hidden, `HYPERLINK` fields linked), hyperlinks and bookmarks, tracked changes shown as accepted, content controls, symbols, math (as italic text), DrawingML pictures (crop, alt text, click links), anchored pictures floated left/right, charts (reusing the PPTX chart parser and view), text boxes and shape groups, VML pictures and text boxes, footnotes and endnotes numbered in reference order. Tables: grid columns, `gridSpan`, `vMerge`, `gridBefore`, widths (dxa/pct), alignment, indent, cell margins, row heights, borders and shading from the table style regions (`tblLook` flags) and direct cell properties.
  - `docx/render.tsx`: HTML rendering with the document's own colors and fonts on a white page in both app themes. Tab stops (left/center/right/decimal, dot/hyphen/underscore leaders) are measured after layout, as in the PPTX preview. Web links open outside the app (http, https and mailto only); bookmark links and note references scroll within the viewer.
  - Zoom: 50% to 300% of "fit", where fit is the page's real size or smaller in a narrow panel.
- Docs: README, npm README, gitlocal.dev home, features hub, Markdown and previews pages, FAQ (text and JSON-LD). `preview-samples/sample.docx` added.

## Verification

- Server tests with coverage, run as a non-root user: 495 passed, thresholds met. As root, the 13 known permission-based tests fail, unrelated to this change.
- UI tests with coverage: 1005 passed, per-file thresholds met. DOCX files: `document.ts` 95.7% branches, `numbering.ts` 94.4%, `properties.ts` 99.5%, `render.tsx` 98.5%, `DocxViewer.tsx` 96.2%.
- `npm run lint`, `cd ui && npx tsc --noEmit -p .`, `npm run build`: clean. The viewer and parser build as separate lazy chunks.
- Chromium against the built app, light and dark theme, wide and narrow window: documents generated by pandoc (headings, lists, table, picture, footnote), python-docx (title border, bullets and numbering, "Light Grid Accent 1" table style, header/footer, page break, picture), a LibreOffice round trip of the latter, and a hand-built file (table of contents with dot leaders and right tabs, heading numbering, highlight, sub/superscript, merged and banded table, floating text box, chart, two-column section).
- Fixed during verification: border, underline and solid-shading colors were read from `w:val` instead of `w:color`; the page's 1px border narrowed the content box so right-tab page numbers wrapped (now a box-shadow outline, plus 1px slack on right stops).
- Not verified here: WebKit (macOS app) [likely the same as Chromium; nothing used is Chromium-specific], and documents written by Microsoft Word itself [none available in this environment; the parser follows the ECMA-376 structures Word writes, and the test builder covers Word-specific forms such as `mc:AlternateContent`, `wps` text boxes, VML fallbacks and complex fields].
- Local install note: `ui` `npm ci` could not fetch the SheetJS CDN tarball from this environment; tests ran with the npm-registry `xlsx` installed locally only. Lockfiles were not changed for this.

## Known limitations

- Pages split only at page and section breaks, not by height, so page numbers and printed page boundaries are not reproduced.
- Comments are not shown. SmartArt and embedded objects show a placeholder. Floating objects are floated left or right, not placed at their exact position. Equations are shown as plain italic text.
- Legacy `.doc` (binary Word 97-2003) is not supported.
