# GitLocal v0.14.1 Release Review

## Scope

- Release: `v0.14.1` (PATCH).
- Theme: PowerPoint decks showing "This presentation has no slides" in the macOS app.
- Release date: 2026-10-18

## Summary of changes

- `parseXml` drops a leading U+FEFF before `DOMParser`. The reported 21-slide generated deck stores
  its `.rels` parts with a UTF-8 byte order mark (slide and presentation parts have none). JSZip's
  text decoding keeps the mark. Chromium and jsdom parse such text; WebKit, used by the macOS app,
  rejected it [likely, not reproduced here: no WebKit in the build environment], leaving the
  presentation's relationships empty, so no slide was found.
- UI only; no server, API or dependency change.

## Verification

- Reported deck in Chromium (Vite dev build) and jsdom: 21 slides, before and after the change.
- `xml.test.ts`: a BOM-prefixed part parses, and `DOMParser` receives the text without the mark.
- `cd ui && npx tsc --noEmit -p .`: clean.
- To confirm on macOS: open the reported deck in GitLocal.app after installing 0.14.1.
