# GitLocal v0.19.1 Release Review

## Scope

- Release: `v0.19.1` (PATCH).
- Release date: 2026-11-22
- Items: read aloud follow-ups, PR #142.
- No new dependency.

## Summary of changes

- Selection kept when reading starts: the Markdown preview no longer replaces its DOM on every re-render (element renderers created once). Read-aloud selections also fall back to text offsets.
- Option+Esc (Alt+Esc off macOS) starts reading, reads a new selection, or stops; Ctrl+Alt+S pauses and resumes. macOS View menu: Read Aloud (Option+Esc), Pause or Resume Reading, Stop Reading, Read Aloud Voices….
- The Read aloud button only starts reading. Voice, speed and install guidance are in a "Read aloud voices" dialog (View options in the browser, View menu in the macOS app).
- Fixes: selections in the HTML preview are read; the click ending a drag-selection no longer moves reading; skipped sentences are cancelled on the client and not started on the server; stopping while paused resumes the audio context; start failures are reported; Escape in a dropdown menu no longer stops reading.
- Markdown images are no longer re-fetched on identical re-renders.

## Verification

- UI tests with coverage: 1142 pass, per-file thresholds met. CI `verify` passed on PR #142.
- `npm run lint`, `cd ui && npx tsc --noEmit`, `npm run build`: clean. Server tests: as root, the same 13 permission-based tests fail as on 0.19.0.
- Built app in Chromium with stubbed local voices: a drag-selected Markdown paragraph stays selected and is read alone; Alt+Esc starts and stops; no preview text node is replaced on start for text, code, CSV, DOCX, PPTX, PDF; the settings dialog opens from View options.

## Known limitations

- The macOS menu changes (Option+Esc key equivalent, new items) were not built or run on a Mac before release.
- With macOS "Speak selection" enabled, the system handles Option+Esc before GitLocal.
- Shortcuts and click-to-move do not work while focus is inside the HTML preview frame.
