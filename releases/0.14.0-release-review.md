# GitLocal v0.14.0 Release Review

## Scope

- Release: `v0.14.0` (MINOR). Supersedes the unpublished `v0.13.10` (PR #121), whose fix ships here.
- Theme: PowerPoint preview features.
- Release date: 2026-10-18

## Summary of changes

- **Links.** `a:hlinkClick` on runs and on shapes/pictures (`p:cNvPr`). External targets open in a
  new window only for `http:`, `https:` and `mailto:`; other schemes are dropped. Internal slide
  targets and `ppaction://hlinkshowjump` (first/last/next/previous) scroll to the slide. Linked
  runs take the theme `hlink` color and an underline unless `a16:hlinkClr val="tx"`.
- **Zoom.** Toolbar steps 50-300% relative to fit-to-width; the slide frame takes the scaled width,
  and the scroll body scrolls horizontally only while zoomed past fit.
- **Hidden slides.** `p:sld show="0"` is marked and dimmed; a toolbar checkbox (shown only when the
  deck has hidden slides) filters them out. Slide numbers keep the deck's numbering.
- **Text columns.** `bodyPr numCol`/`spcCol` render as CSS columns filled in order (`column-fill:
  auto`); text that overflows the box falls back to balanced columns so nothing spills sideways.
- **Tab stops.** `a:tabLst` and `defTabSz`; tab characters become measured gaps sized after layout
  (left, center, right; decimal treated as right).
- **Video/audio.** Pictures with `a:videoFile`/`a:quickTimeFile`/`a:audioFile`/`a:wavAudioFile`/
  `a:audioCd` get a badge; no playback.
- **0.13.10 fix.** Runs without `a:rPr` take formatting from the paragraph's `a:pPr/a:defRPr`.
- UI only; no server, API or dependency change.

## Verification

  94% branches, `pptx/` files 94-99% branches.

  land on their positions, two-column text fills in order, zoom 150% scrolls sideways, a slide
  link focuses the target slide, hidden slide tagged and dimmed, video badge shown.

## Known gaps / follow-ups

- No media playback; no slide thumbnails or "go to slide" navigator.
- Tab stops in vertical or right-to-left text are measured as if left-to-right [likely wrong there].
- SmartArt without a saved drawing part; EMFs recorded with world transforms or OpenGL.
