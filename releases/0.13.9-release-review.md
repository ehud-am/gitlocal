# GitLocal v0.13.9 Release Review

## Scope

- Release: `v0.13.9` (PATCH). Feature PR #119 (merged).
- Theme: PowerPoint preview quality (spec label `050-pptx-preview-quality`, issues #99 and #97).
- Release date: 2026-10-11

## Summary of changes

- **Backgrounds (#99).** `p:bgRef idx` resolves by position into the theme's `bgFillStyleLst`
  (1000+ offsets); gradient, pattern and picture backgrounds render as CSS layers.
- **EMF/WMF images (#97).** Converted to SVG with `rtf.js` (MIT) and its `codepage` dependency
  (Apache-2.0), lazy-loaded, no network calls. An EMF drawn under a non-identity world transform
  keeps the "not available" placeholder, since rtf.js ignores those records.
- **Shapes and text.** Preset/custom geometry as SVG outlines, line and dash styles,
  slide → layout → master → theme text-style inheritance, bullets, tables, cached-value charts,
  picture crops, per-slide slide numbers. Empty placeholders render nothing, as in slide show.
- **Dependencies.** `fast-xml-parser` removed (parsing uses the browser `DOMParser`); `rtf.js`
  and `codepage` added to `ui/`.
- No server or API change; both distributions share the UI.
