FEATURES

What GitLocal helps with

A local, GitHub-style viewer for the code your AI agent wrote. Here is everything it does, grouped by what you are trying to get done.

Find your way around

Browse like GitHub

A lazy-loading, keyboard-navigable file tree for regular folders and git repositories, right on your machine.

Learn more →

Search intentionally

Repository-wide search with current-folder and Markdown-focused scopes, plus file-level find inside the current file.

Learn more →

Read Markdown clearly

GitHub-like rendering with relative links, heading anchors, find highlights, and share/copy actions. No IDE required.

Learn more →

Preview beyond code

Built-in viewers for PDF, SVG, CSV, Excel, and PowerPoint files alongside Markdown and images, rendered locally where GitHub's web UI often falls back to a raw download link.

Learn more →

See what changed

Review what changed

A changed-files panel for modified, deleted, untracked, generated, and local-only paths, plus active-file refresh notices.

Learn more →

Understand git state

A plain-language repository summary — branch, remote, sync, and local changes — backed by technical detail when you need it.

Learn more →

Make changes and hand off

Make small edits safely

Create, update, and delete files right from the viewer, with warnings before you lose unsaved work and protection against overwriting changes made elsewhere.

Learn more →

Hand off to your agent

A built-in terminal docked to the right, left, or bottom of the window, so you can run Claude, Codex, or any command without leaving GitLocal.

Learn more →
