FIND YOUR WAY AROUND

Search your repository

Look across the whole repository, or narrow to the folder or the documents you care about, and then find text inside the file you have open.

What you get

  • A dedicated repository search. It lives on its own surface so results are easy to scan.
  • Scopes that match how you look for things. Search the current folder, or focus on Markdown files when you are hunting for a document.
  • Generated and local files, on your terms. Controls let you decide whether generated or local-only files show up, and results come with counts.
  • Find inside the current file. File-level find highlights matches in the file you are reading, including in rendered Markdown.

Try it in one command

npx gitlocal
