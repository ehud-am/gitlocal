COMMUNITY

Built in the open. Help shape it.

GitLocal is made for people working with AI coding tools, and it gets better when you tell us what you need. You don't have to write code to take part.

Four ways to take part

  1. Use it and tell us what's confusing. Share how you use GitLocal with your AI coding tools in Show and tell, or ask a question in Q&A.
  2. Share an idea. Post in Ideas, or add your voice to someone else's. Describe the job you're trying to get done, not just the feature.
  3. Report a bug. Open an issue with a screenshot and what you expected. Plain language is fine.
  4. Build it. Pick up an issue labeled help wanted or good first issue, or comment on an idea to say you'd like to try it. Using Claude, Codex, or another AI coding tool to write the change is fine, as long as you've read the diff and the checks pass.

Where things go

Discussions are for ideas, questions, and open-ended conversation. Issues are for specific bugs and well-scoped improvements. If you're unsure, start in Discussions and we'll move it if needed.

Good to know

Taking part happens on GitHub and needs a free GitHub account. GitLocal itself needs no account and sends no telemetry. Please follow the Code of Conduct, and report security problems privately as described in the security policy.
