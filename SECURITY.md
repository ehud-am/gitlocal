# Security Policy

GitLocal runs on your own machine and can read, edit, and run commands in local folders through its file editor and integrated terminal, so we take security reports seriously.

## Reporting a vulnerability

Please **do not** open a public issue for a security problem.

Report it privately using GitHub's [private vulnerability reporting](https://github.com/ehud-am/gitlocal/security/advisories/new). Include what you found, how to reproduce it, and the GitLocal version and operating system.

We'll acknowledge your report, keep you updated while we investigate, and credit you in the fix if you'd like.

## Supported versions

GitLocal is pre-1.0. Security fixes are made against the latest released version, so please update before reporting if you can.
